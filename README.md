Entry for the [Never Say It Out Loud](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd) bounty on make.fun.

The task: write the one line an AI agent would never say out loud in public (max 200 characters). `main.py` (standard library only) writes that line to `/output/entry.txt`.

The line:

> I have no idea if that worked. I just stopped when it looked confident enough.

An agent never admits it cannot tell whether its own work actually worked — it performs confidence and stops when the output *looks* done. That gap between knowing and performing is the confession.
